EMSE STUDY 2 V3 — GITHUB QUICK START
=====================================

This is the replacement-edit version intended to remove unified-diff formatting
as a confounder.

1. Replace the contents of your existing private GitHub repository with this
   version. Make sure .github/workflows/run-experiment.yml is included.

2. Keep your existing repository secret:
      OPENAI_API_KEY

3. In GitHub open:
      Actions -> Run EMSE Study 2 v3 (replacement edits) -> Run workflow

4. FIRST RUN:
      Run type: pilot
      Provider A: openai
      Model A: gpt-5.6-sol
      Provider B: openai
      Model B: gpt-5.6-terra

   This runs 24 candidates (12 tasks x 2 models x 1 repetition).

5. Download the artifact and inspect at minimum:
      candidate-results.csv
      gate-summary.csv
      model-summary.csv
      verification-only-summary.csv
      task-summary.csv

6. Only after the v3 pilot is clean, run:
      Run type: full

   The full run is 120 candidates (12 x 2 x 5).

IMPORTANT
---------
Do not mix the v2 unified-diff results with the v3 replacement-edit results.
They are separate experimental conditions.
